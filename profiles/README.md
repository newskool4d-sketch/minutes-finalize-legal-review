# 기관·관할 프로필

공통 스킬은 법령·기관별 운영 기준을 하드코딩하지 않습니다. 실제 업무에서는 아래 원칙에 따라 프로필을 선택합니다.

- 프로필에는 관할, 기준일, 적용 법령·고시, 조치 점수 기준, 내부 확인 필요 항목을 적습니다.
- 법령이 바뀌면 공통 `SKILL.md`가 아니라 해당 프로필만 갱신합니다.
- 프로필이 없거나 기준일이 불명확하면 `L 법무 확인`으로 처리합니다.
- 기관별 내부 규정은 공개 가능한 범위에서만 배포합니다.

현재 포함된 프로필:

- `education-rights-ko.md`: 한국 교육활동 침해·교권보호위원회 업무용
- `generic-committee-ko.md`: 한국 공공기관 일반 심의·위원회 업무용
