# 한국 학교폭력대책심의위원회 프로필

- 관할: 대한민국. 특정 교육청의 운영기준을 고정하지 않음
- 프로필 ID: `school-violence-ko`
- 버전·확인일: 2026.11.16.1 / 2026-11-16
- 실행 규칙: [legal-profiles.json](legal-profiles.json)의 전용 후보 규칙 8개, 필수 확인 7개
- 상태: 공식 근거를 연결한 검토 후보 규칙. 사건별 실무·법무 승인이나 위법성 자동 판정이 아님

## 검토 범위

1. 학생별 행위·피해·증거와 복수 사안의 경계를 구분한다. 쌍방·가담이라는 표현으로 모두의 책임을 일괄 확정하지 않는다.
2. 피해·가해 양측의 통지·의견 제출, 전문가 요청 및 의견청취 기록을 확인한다.
3. 실제 본위원회/소위원회 구성·위임·제척·기피·회피·표결을 관할 운영기준과 대조한다.
4. 조치 근거와 의무교육 제한을 대조한다. 학폭 전학은 법 제17조제1항제8호, 퇴학은 제9호이며 교권 조치 번호와 다르다.
5. 심각성·지속성·고의성, 반성·선도 가능성, 양측 보호자를 포함한 화해 정도 및 피해학생 장애 여부를 확인한다. 교권의 관계회복 항목을 그대로 복제하지 않는다.
6. 회의록 기록·보존과 공개본 처리를 분리한다. 발언별 법률위험은 수정/삭제의 자동 승인이 아니다.

## 적용 시점

- **발생일:** 행위·사실과 해당 조치 기준의 시점 확인. 제19741호 부칙 제5조의 분리 요청 적용례는 발생일을 사용한다.
- **신고일:** 제19741호 부칙 제4조는 2024-03-01 이후 신고된 사안에 제17조 개정규정을 적용하도록 한다.
- **학교장 인지일:** 시행령 제35504호 부칙 제2조는 2025-05-22 이후 인지한 사안에 분리 예외 개정을 적용한다.
- **심의일:** 제21723호 부칙 제2조는 2026-06-02 이후 개최 심의위원회부터 장애학생 또는 보호자 요청 시 전문가 의견청취 의무를 적용한다.
- **처분일:** 요청·통지·조치의 시점과 부칙을 사건별로 대조한다. 발생일·신고일 기준을 처분일 하나로 대체하지 않는다.

MST 286361에는 2027-01-01 시행예정본도 있으며 제15조의2 시행 유예가 포함된다. 법률 전체가 2027년부터 시행되는 것으로 오해하지 않는다. 이 카탈로그는 2026-06-02 시행본만 고정한다. 모든 과거 시행본을 포함하지 않으므로 확인 범위 밖의 날짜는 별도 연혁 확인으로 남긴다.

## 필수 경고

- 고시 제2조제4항은 보호자 특별교육 관련 법 제17조제9항을 인용하지만 현행법의 해당 내용은 제17조제13항이다. `stale_internal_cross_reference`를 남기고 상위법 원문을 대조한다.
- 고시 제3조제1항의 전문가 의견에 관한 재량 문구로 2026년 개정 법률의 요청 시 청취의무를 약화하지 않는다.
- 법 제21조제3항의 회의록 공개 신청자는 피해학생·가해학생 또는 보호자다. 제3자 정보공개청구에 이 예외를 자동 적용하지 않는다.
- 시행령 제33조의 비밀 범위에는 개인별 발언도 포함된다. 이것이 원본 삭제나 전면 비공개 자동 결정의 근거는 아니다. 문장 비공개는 실무자가 청구 조건·근거·위치를 확인해 별도로 승인한다.
- 점수·조치 자동 산정, 사실확정, 위법/적법 결론, 담당자 승인 기록 자동 작성은 하지 않는다.

법령 MCP에는 법령명·조문·기준일 등 비식별 최소 질의만 전달한다. 앱 프로필 실행은 로컬 카탈로그를 사용하며 원문을 자동 전송하지 않는다. 자세한 근거 수준은 [M2 근거 기록](../references/m2-legal-profile-evidence.md)을 참조한다.
