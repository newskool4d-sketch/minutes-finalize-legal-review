# 회의록 법률검토 체크리스트

## 파일·정본성

- [ ] HWPX가 정상적으로 열리고 문단·표 구조가 보존되는가
- [ ] 입력 단계와 파일 해시가 기록되었는가
- [ ] 원본·1차 수정본을 덮어쓰지 않았는가
- [ ] 전사 원본이 없으면 전사 정확도 검증 불가가 표시되었는가

## 기본정보·사실

- [ ] 시나리오와 회의명·일시·장소·사안번호가 일치하는가
- [ ] 발언자·직위·참석자·배석자가 일치하는가
- [ ] 발언·사실·결정·표결의 순서가 보존되는가
- [ ] 사실 확정 전 문장에 출처가 붙어 있는가
- [ ] 전언·추측·인상과 직접 경험이 구분되는가

## 법률위험

- [ ] 절차·사실인정·재량판단·편견·개인정보·기록무결성·명예·법적 근거 중 해당 위험 유형이 표시되었는가
- [ ] 각 위험 항목에 문구·사실관계·법적 쟁점·적용 근거·권고 조치가 연결되었는가
- [ ] 외모·체격·눈빛·가정·교우관계·평판이 쟁점과 직접 관련되는가
- [ ] 정신건강·장애·복약 정보가 공식 자료인지 단순 전언인지 구분되는가
- [ ] 현재 사안과 별개인 과거 사건·평소 행실이 성향 증거로 사용되지 않는가
- [ ] “보복”, “2차 가해”, “개선 여지 없음” 등 의도·인격 단정이 중립화되었는가
- [ ] 학생·보호자의 해명·사과·반대 진술이 누락되지 않았는가

## 점수·절차

- [ ] 심각성·지속성·고의성·반성·관계회복 점수별 이유가 분리되어 있는가
- [ ] 지속성과 고의성이 서로 혼동되지 않는가
- [ ] 사안이 여러 건이면 사안별 점수 또는 통합 이유가 있는가
- [ ] 학생·보호자 의견 제출 기회와 불참·서면 처리가 기록되었는가
- [ ] 제척·기피·회피와 비밀유지 안내가 기록되었는가
- [ ] 본문과 결과표의 표결 수치·조치가 일치하는가
- [ ] 사건 발생일·심의일·처분일 기준의 법령·고시·부칙 시행 버전이 확인되었는가
- [ ] 법령명·조문·시행일·조회일·공식 출처 식별자가 검토표에 기록되었는가
- [ ] 원격 MCP 사용 시 비식별 최소 질의만 전송했고 기관 승인을 확인했는가

## 출력·승인

- [ ] 결재용 실명 정본 HWPX와 정보공개 청구용 비실명 HWPX가 별도로 생성되었는가
- [ ] 두 HWPX의 회의명·사안번호·일시·의결·표결·발언 순서·표와 문단 구조가 일치하는가
- [ ] 정보공개 청구용 비실명 HWPX에서 승인된 식별정보 처리 외의 삭제·요지화·사실 변경이 없는가
- [ ] 문장 비공개가 있으면 정보공개 청구용에만 적용됐고, 위치·사유·실무자 판단·정확히 한 곳 처리 기록이 있는가
- [ ] 결재용 실명 정본에 비실명 처리용 표식·대체명이 남지 않았는가
- [ ] 비실명처리 대장에 위치·처리 방식·사유·승인상태가 기록되었는가
- [ ] 두 HWPX가 모두 정상적으로 열리는가
- [ ] 법률위험 검토표가 별도로 생성되었는가
- [ ] 높은 위험 항목마다 발언 요지·확인 자료·공식 근거·시행일·사건 기준일이 기록되고 `L 법무 확인`으로 남았는가
- [ ] 변경 전·후 요지·사유·근거·검토자·승인상태가 기록되었는가
- [ ] `D 삭제 검토`가 담당자 승인 없이 반영되지 않았는가
- [ ] 중대한 조치·민감정보·상반 증거는 `L 법무 확인`으로 표시되었는가
