# 법률위험 판정 매트릭스

회의록 문구가 불편하거나 부적절하다는 이유만으로 법률위험으로 단정하지 않는다. 각 항목에 대해 `문구 → 사실관계 → 법적 쟁점 → 적용 근거 → 권고 조치`를 연결한다.

## 위험 유형

| 유형 | 우선 확인할 상황 | 기본 조치 |
|---|---|---|
| 절차 | 통지, 의견진술, 제척·기피·회피, 의사정족수, 표결, 이유 제시 누락 | `V` 또는 `L` |
| 사실인정 | 전언·추측을 사실처럼 적음, 반대 자료·유리한 진술 누락, 발언 왜곡 | `V`, `N` 또는 `L` |
| 재량판단 | 무관한 요소 고려, 필수 고려 요소 누락, 점수·조치 불일치 | `V` 또는 `L` |
| 편견·예단 | 외모·가정·평판·과거행위·인격을 근거로 결론을 암시 | `N`, `V` 또는 `L` |
| 개인정보 | 민감정보·제3자 정보·직접식별정보가 목적 범위를 넘음 | 결재용은 `L`, 정보공개 청구용은 승인된 `D` |
| 기록무결성 | 발언자, 날짜, 사안번호, 의결, 표결 수치 불일치 또는 사후 수정 근거 없음 | `V` 또는 `L` |
| 명예·분쟁확대 | 확인되지 않은 범죄·질환·의도·평판을 사실처럼 기록 | `N`, `V` 또는 `L` |
| 법적 근거 | 폐지·개정 전 조문, 사건 당시 미시행 기준, 잘못된 조문 인용 | `V` 또는 `L` |

## 위험 수준

| 수준 | 판단 기준 | 정본 처리 |
|---|---|---|
| 높음 | 처분의 절차적 적법성·사실인정·중대한 조치에 직접 영향, 또는 민감정보 침해가 중대함 | `L 법무 확인`; 결재용 정본 확정 보류 |
| 중간 | 판단 편향·분쟁 확대 가능성이 있으나 자료 대조 또는 중립화로 보완 가능 | `N` 또는 `V`; 담당자 승인 필요 |
| 낮음 | 법률효과보다 가독성·표현·경미한 최소화 문제에 가까움 | `S` 또는 `K`; 변경이력 기록 |

## 처리 범위 원칙

- 결재용 실명 정본: 사실·의결·표결·발언 경위를 보존한다. `D`는 담당자 승인 없이는 반영하지 않는다.
- 정보공개 청구용 비실명본: 결재용 실명 정본을 기준으로 승인된 직접식별정보만 처리한다. 사실·의결·표결·문단·표 구조를 임의로 바꾸지 않는다.
- 근거가 부족하면 위험도를 낮추지 말고 `V 근거 확인`으로 남긴다.
