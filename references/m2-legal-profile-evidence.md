# M2 법률 검토 프로필 근거·적용 시점

확인일: 2026-11-16 (대한민국). 대상: 교권보호 → 학교폭력 순서의 실행 프로필 구현. 실제 사건자료는 사용하지 않았다.

## 범위와 법적 판단의 경계

M2는 발언별 위험 **검토 후보**, 공식 근거 참조, 날짜별 버전 확인 필요사항, 담당자 확인표를 제공한다. 정규식 적중은 위법성 판정이 아니며, 미적중도 문제가 없다는 증거가 아니다. 법률전문가의 사건 적용 검토와 실무 검수는 별도다. 과거 모든 법령·판례·관할 운영규정·정보공개청구 유형을 망라한 법률 자문 시스템은 아니다.

공식 법령 MCP의 `search_law`, `get_law_text`, `legal_analysis(mode=applicable_law)`, 행정규칙 검색·조회로 법령명·MST·공포/시행일·조문·부칙·고시 별표를 확인했다. 국가법령정보센터 웹 원문과도 대조했다. 교권 일부 전체 본문 URL은 점검/본문 누락으로 읽히지 않았으며 해당 조문은 MCP 본문과 공식 조문정보 페이지를 사용했다. 페이지 헤더만 조회한 것을 조문 전체 검증으로 표시하지 않는다.

## 날짜 계약

`legal_context`는 위원회 종류·국가 관할과 다음 날짜를 각각 가진다. 모르는 날짜는 `null`로 둔다.

| 필드 | 의미 | 중요한 사용 예 |
|---|---|---|
| `incident_date` | 사건 발생일 | 행위·조치 기준, 학폭 제19741호 부칙 제5조 |
| `report_date` | 신고일 | 학폭 제19741호 부칙 제4조 |
| `knowledge_date` | 학교장 인지일 | 교권 제21350호 부칙 제2조, 학폭 시행령 제35504호 부칙 제2조 |
| `deliberation_date` | 실제 심의 개최일 | 학폭 제21723호 부칙 제2조, 절차·위원 구성 |
| `disposition_date` | 처분일 | 요청·통지·조치 및 경과조치 대조 |

교권 신설 긴급조치는 발생일만으로 선택할 수 없고, 학폭 장애학생 전문가 요청 조항은 심의일을 기준으로 하는 적용례가 있다. 날짜 종류를 하나로 합치거나 자동 추정하지 않는다. 반복 행위·재심·복수 심의일·과거 여러 버전이 걸친 사안은 이번 단일 날짜 외피로 완결 처리하지 말고 사안 분리 및 별도 법무 검토가 필요하다.

## 확인 범위와 보수적 중단

- `effective_from`은 카탈로그에 확인한 **전체 법령 시행본의 시작일**이다. 해당 조문이 처음 만들어진 날짜라고 뜻하지 않는다.
- `effective_to_exclusive`는 이 시행본 묶음의 지원 상한이다. 교권 법률은 2026-11-20, 학폭 법률은 2027-01-01이다. 법률 전체가 그날 폐지되거나 모든 조문이 변경된다는 뜻이 아니다.
- `verified_through`는 2026-11-16이다. 그 뒤 날짜를 현재 카탈로그로 검증 완료 처리하지 않는다. 앱이 실행 때마다 외부 법령을 조회하는 기능은 아니다.
- 필요한 날짜가 없거나 확인 시행본 이전/이후면 `needs_date_verification`과 미확인 사유를 반환한다. **최신 조문으로 소급 대체하지 않는다.**
- 날짜가 확인 범위 안이어도 법적 적용·부칙 해석 확정이 아니라 버전 범위 일치만 의미한다. `requires_human_review`와 미확인 증빙 목록을 유지한다.
- 특정 규칙에 해당하지 않는다면 담당자가 자료를 확인하여 비해당 사유를 기록해야 한다. M2는 그 판단 기록을 자동 생성하지 않는다.

## 핵심 발견과 구현 반영

1. 교권은 전학 제6호·퇴학 제7호, 학폭은 전학 제8호·퇴학 제9호다. 규칙·사유·검토 요소를 프로필별로 분리했다.
2. 교권은 학생과 교원의 관계회복·반성 및 선도 가능성, 학폭은 학생·보호자 간 화해 등의 요소를 해당 시행령과 연결한다. 가중·감경·점수 계산은 구현하지 않는다.
3. 교권법 제21350호 부칙 제2조의 인지일, 학폭법 제21723호 부칙 제2조의 심의일, 제19741호 부칙의 신고/발생일을 별도로 확인한다.
4. 학폭 고시의 법 제17조제9항 내부 인용은 현행 보호자 특별교육 제13항과 어긋난다. `stale_internal_cross_reference`를 유지하고 별도 필수 확인표를 제공한다. 고시의 재량 문구도 법률상 요청 시 의무를 약화하지 않는다.
5. 양 위원회의 비밀유지·개인별 발언 범위와 당사자 공개 신청 규정을 연결하되, 제3자 정보공개청구의 자동 허용/거절이나 원 회의록 삭제로 바꾸지 않는다.
6. 본위원회·소위원회의 실제 위임·운영기준은 기관별 자료로 확인한다. 전체 정수를 기계적으로 적용하는 자동 정족수 판정은 하지 않는다.

## 최종화 금지 상태

`rules_implemented`는 전용 규칙이 작동한다는 기술 상태다. 법률 검토 완료가 아니다. 후보·확인표·검수요약은 `legal_conclusion: not_determined`, `requires_human_review: true`, `external_release_authorized: false`를 유지한다. 과거 공통 탐지 규칙의 후보는 `unlinked_common_rule`로 구분하며 공식 법률 근거가 확인된 것으로 승격하지 않는다.

실무·법무 검수, 사건별 적용법 확정, 관할 규정, 실제 HWPX 한글 열기, 정보공개 최종 결정, 승인된 실제 3~5건 운영지표는 별도 후속이다. 코드 회귀시험 통과만으로 이 항목을 완료 처리하지 않는다.
