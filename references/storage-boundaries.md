# 소스·설치본·사건자료의 저장 경계

| 구분 | 역할 | 보관 범위 |
|---|---|---|
| 소스 정본 | Git으로 개발·검증하는 저장소 | 코드, 설명, 합성 테스트·예시만 포함 |
| Codex·Claude 설치본 | 검증한 소스의 실행용 복사본 | 배포 목록과 설치 영수증; 여기서 개발하거나 사건자료를 보관하지 않음 |
| 제한 작업공간 | 기관이 승인한 별도 절대경로 | 실제 HWPX, 시나리오, 원문 포함 모델·승인안, 법률 검토, 근거, 산출물·검수요약 |
| 비식별 운영지표 | 지속 개선의 집계 근거 | 실명·원문 없는 수치와 허용된 사유 코드; 실자료와 별도로 관리 |

제한 작업공간은 저장소와 설치 폴더의 **밖**에 둔다. 이름을 `case-data`로 정하거나 `.gitignore`에 넣는 것만으로 승인·접근통제·보존기간이 설정되지 않는다. 폴더 권한·저장 위치·보존 및 폐기는 기관 정책과 담당자 결정을 따른다. 도구는 이를 자동 승인하거나 변경하지 않는다.

명령은 소스 또는 설치본에서 실행하되 입력·출력은 `$caseRoot` 같은 별도 절대경로 변수로 전달한다. 공유 가능한 해시·집계라도 다른 자료와 결합하면 사건을 연결할 수 있으므로 자동 공개하지 않는다. 검수요약에는 원문·실제 경로를 출력하지 않지만 내부 검수 기록으로 취급한다.

개발 수정은 소스 정본에 반영하고 검사 후 설치기로 동기화한다. 설치·검증이 출력한 `VERIFY_COMMAND`의 대상 경로와 신뢰할 소스 경로를 유지한다. 설치 영수증만으로 원본의 신뢰성을 판단하지 않는다. 백업·실패 후보는 활성 skills 밖에 보존하며 자동 삭제하지 않는다.

기관별 스킬 레지스트리가 있으면 이 스킬 항목의 소스 역할·설치본 지문만 대조한다. 레지스트리나 전역 설정을 자동 변경하지 않으며, 불일치하면 정확한 파일·행·수정안을 별도로 제시한다. 레지스트리가 없어도 이 스킬의 실행에는 지장이 없다.
